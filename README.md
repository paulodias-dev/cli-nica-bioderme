# Clínica Bioderme

Landing page institucional da Clínica Bioderme.

Desenvolvimento e autoria: [Fluxo Sistemas](https://fluxosistemas.com.br)

## Execução local

Pré-requisito: Node.js

1. Instale as dependências:
   `npm install`
2. Inicie o ambiente de desenvolvimento:
   `npm run dev`
3. Gere a versão de produção:
   `npm run build`
